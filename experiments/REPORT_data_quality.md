## 1. 결측치 실측 진단

### 1.1 컬럼별 결측률 (실측, 전체 행 기준)

| 컬럼 (16개) | 결측 행 | 비율 |
|---|---|---|
| `asof_pitcher_prev{1,3,5}_game_{success,middle}_rate` (6종) | 29,185 | **1.979%** (동일 패턴) |
| `asof_batter_{success,middle}_rate` (2종) | 830 | 0.056% |
| `asof_pitcher_{success,reverse,middle,ball,strike}_rate` + `{fastball,breaking,offspeed}_rate` (8종) | 792 | 0.054% |
| 그 외 32컬럼 (경기상황 15·ID·팀·n 계열) | 0 | 0% |

### 1.2 결측 패턴 — 무작위가 아니라 정확히 3개 그룹

- **G1 (29,185행, 1.92%)**: prev_game 6종만 결측. → 아래 1.4의 **신규 발견 참조**
- **G2 (792행)**: 투수 asof 8종 결측, **전부 `asof_pitcher_n==0`** (이력 0구) — 시즌 첫 등판
- **G3 (830행)**: 타자 asof 2종 결측, `asof_batter_n==0` — 타자 첫 등장
- G2 결측 행 수(792) = pitcher_id 고유값(792), G3(830) = batter_id 고유값(830) → **결측 원인이 "데뷔" 하나로 수렴** (무작위성 0)

### 1.3 결측 ↔ target 연관 (실측 Δ)

| 그룹 | 결측 행 target | 전체 평균 | Δ |
|---|---|---|---|
| G1 (prev_game 결측) | 0.5508 | 0.5232 | **+0.0276** |
| G2 (투수 데뷔) | 0.5518 | 0.5238 | +0.0280 |
| G3 (타자 데뷔) | 0.6024 | 0.5237 | **+0.0787** |

- **결측이 정보성 신호다.** G3(타자 이력 없음)가 성공률 +7.9pp — 소표본(830행)이지만 방향이 뚜렷.
- ⚠️ 단, **G1의 Δ는 시즌별로 역전**: 2019~2022 +0.021~+0.027 → 2023 −0.010 → 2024 **−0.024** (기존 REPORT 확정). 지시자를 넣을 땐 **2024 홀드아웃 기준으로만 판단**할 것.

### 1.4 【신규 발견】 G1의 정체 — "데뷔"가 아니라 "복귀/공백"

- G1 29,185행 **전부 `asof_pitcher_n`이 존재** (결측 0행). 즉 이들은 이력이 있는 투수다. (진짜 데뷔는 n==0인 G2 792행뿐)
- G1을 asof_n 구간으로 나누면:

| asof_pitcher_n | 행 수 | target |
|---|---|---|
| [0, 10) | 7,632 | 0.5449 |
| [10, 50) | 14,610 | 0.5563 |
| [50, 100) | 6,844 | 0.5463 |
| [100, 1000) | 99 | 0.5051 |

- 해석: **최근 N경기 이력이 없는 투수(시즌 초·경기 공백·복귀)는 대체로 성공률이 높다** — 단, 누적 이력 100구 이상이면 기준치(0.505)로 회귀.
- **우리 모델 영향**: ① G1을 단순 "데뷔/신인"으로 취급하면 **틀린 라벨링**. ② test 5행 샘플에 이미 같은 케이스 존재(`TEST_000017`: asof_n=86인데 prev1~5 전부 결측). ③ G1의 asof_n 구간 × target 곡선이 **누적 이력 vs 최근 이력의 결손**을 대리하므로, 지시자 설계 시 `asof_n`과의 교호작용을 명시할 것.

### 1.5 현재 처리 방식 평가

- **현행 (권장 유지)**: SimpleImputer 안 씀. LGBM/HGB NaN 네이티브로 결측을 split 신호로 사용. → **적절**
- 금지: 0.5/-1/평균 대체 — G1/G2/G3의 정보성(+0.03~+0.08)이 소실되고, 대체값이 "성공률 0.5"처럼 학습됨.
- 시즌별로 G1 결측률: 2019 5.17% → 2024 1.44% (하락). head-50k 샘플에 2019 결측이 몰리는 **샘플링 편향** 주의 (기존 발견 재확인).

## 3. 전처리 상태 점검

### 3.1 다운캐스팅 필요성 — YES (실측 49% 절감)

- 실측: int32/float32/category 적용 시 **245MB** vs 전부 float64 가정 630MB → **-49%**
- 10시드 로짓평균 + 다중 CV에서 로드 반복 → 메모리·속도 직접 개선. `usecols` + dtype 지정을 파이프라인 표준으로 고정 권장 (현재 GIHO 파이프라인이 float64 로드 후 일부만 변환 중이면 통일).

### 3.2 범주형 인코딩 — 문제없음 (실측 카디널리티)

| 컬럼 | 고유값 | HGB(255 제한) | LGBM |
|---|---|---|---|
| top_bottom / game_type / pitcher_hand / batter_hand | 2 | OK | OK |
| base_state | 8 | OK | OK |
| pitcher_team_id / batter_team_id | 13 | OK | OK |
| **pitcher_id / batter_id** | **792 / 830** | **초과(불가)** | 수치형으로 처리 권장 |

- 범주형은 전부 저카디널리티 → one-hot/category 무난. pitcher/batter_id만 HGB에서 수치형(int)으로 두는 현재 방침 정당 (이미 ID 인코딩 자체는 기각됨).
- 매치업 `(pitcher_team, batter_team)` 조합 96종 — 필요시 범주형 추가 가능하나 카디널리티 관리 용이.

### 3.3 스케일링 — 불필요 (트리 모델)

- LGBM/HGB는 스케일·단조변환에 불변. li(0~10.8), win_expectancy(0~100), rate(0~1) 혼재해도 무해. **스케일러 도입은 리스크만 추가** (추론 파이프라인 복잡화).

### 3.4 결측 fallback 전략 — 현재 방식 유지

- asof 16종: NaN 그대로 (정보성 확인됨, §1.3). 대체 금지.
- 경기상황 15종: 결측 0 — 처리 불필요.
- 범주형: 결측 0.
- 결론: **전처리 상태는 "충분"**. 추가로 필요한 건 없고, 다운캐스팅 표준화만 실행.

### 4.3 asof_pitcher_n 분포 — 소표본 비중 (실측)

- quantiles: p25=684 / p50=1,776 / p75=3,725 / p90=6,526 / p99=11,870
- **소표본(n<30)은 1.57%에 불과**, n<100도 4.85%. 전체 행의 **87.3%가 n≥300**.
- 진짜 cold-start(`n==0`)는 792행 (0.05%) — 이미 §1 G2와 동일.
- **우리 모델 영향**: "투수 소표본" 문제는 행 기준으론 드묾 → 소표본 보정(예: rate에 n 가중)은 효과가 제한적. 대신 **n==0(데뷔)·n<10(초보) 마커**를 별도 피처로 두는 게 효율적 (비율은 낮아도 target 차이 +0.02~+0.03 실존).

## 5. EDA 추가 필요성 (기존 EDA와 비중복, 실측 기반)

기존 `waveb_eda_*` 4종이 다룬 것(시즌 드리프트·월 패턴·상관구조·ID 안정성·매치업·count/LI/팀·trackman 무용)은 **제외**. 아래는 새로 실측해 유망함을 확인한 포인트:

1. **【검증 1순위】 recent gap = `prev1_success − asof_success`** (실측)
   - 하위 25% (직전 폼 저하): target 0.5049 vs 상위 25% (직전 폼 급등): **0.5406** → **+3.6pp 스프레드**
   - 단독 corr는 +0.028로 약하지만, **비선형(급등/급락)**으로 사용하면 실질 신호. "직전 경기 폼 변화"는 기존 EDA가 못 본 새 축.
2. **【검증 2순위】 최신성 역전**: 누적(asof) corr +0.086 > prev1(직전) +0.062. 직전 1경기가 누적보다 약함 → **최근성 가중 피처(예: exp decay)보다는 누적+gap 조합이 유망**. 실측이 "최근 컨디션이 가장 강한 단조 신호"라는 기존 결론과 다름 → 게이트로 재검증할 가치.
3. **【검증 3순위】 G1 "복귀/공백" × asof_n 교호작용** (§1.4) — prev 결측의 target이 asof_n 구간에 따라 0.505~0.556로 다름. 지시자 1개로는 놓치는 분해 가능성.
4. **【검증 4순위】 debut_year / 신인 마커** (§4.2) — 신인 비율 14~22% 상수. season 드리프트 분해 도구.
5. **【저순위】 특수 팀 22/23/25** (§2.3) — 단일 투수(23819) 292행이 target 0.42로 스파이크. 유무 확인용.
6. **pitchmix 중복 확인 (실측)**: fastball+breaking+offspeed 합 = **정확히 1.0** (100% 행) → **완전 다중공선성**. 3개 중 2개만 쓰거나 1개를 기준 비율로 변환하면 1컬럼 절약. (모델 영향은 미미하지만 정리 가치)

→ 권장 실행: ①②③을 한 번의 게이트 실험(2024 홀드아웃, R-only)으로 묶어 ±여부 판정. **모델 학습 금지 조건 때문에 여기선 실험하지 않음** (실행 우선순위 §6).

| 3 | **G1 복귀 마커 × asof_n 구간 교호작용 게이트** | 30분 | asof_n 구간별 0.505~0.556 (§1.4) | G1 지시자 시즌 역전(2024 −0.024) → 2024로만 판단 |
| 4 | **debut_year(신인 마커) 게이트** | 20분 | 신인 14~22%/년 상수 (§4.2), season 드리프트 분해 | 없음 |
| 5 | **pitchmix 3→2컬럼 정리** | 5분 | 합=1.0 완전 공선 (§5-6) | 모델 변화 미미 |
| 6 | 특수 팀 22/23/25 존재 확인 (학습 유지) | 5분 | target 편향 실측 (§2.3) | 낮음 |
| 7 | 소표본 rate 보정 (n 가중/클리핑) | **제외** | n<30 불과 1.6% (§4.3) — 효과 제한 | 불필요 |

**1~5 실행 시 총 1시간 40분.** 모두 "품질 진단 기반 신호"로, 데이터 자체 수정(결측 대체·이상치 제거·스케일링)은 **어떤 것도 필요 없음** — 그 판단을 내린 것이 이 리포트의 핵심 결론.
