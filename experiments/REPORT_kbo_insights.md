## 5. KBO 특수성

### 5-1. 2024 ABS(자동 투구 판정) 도입의 영향

R 경기 성공률: 2023 0.5031 → 2024 0.4897 (**-1.3pp**). 그러나 하락이 **카운트별로 균일하지 않음**:

| 카운트 | 2023→2024 변화 (R) | | 카운트 | 2023→2024 변화 (R) |
|---|---|---|---|---|
| 1-1 | **-2.1pp** | | 1-2 | -0.9pp |
| 2-0 | **-2.0pp** | | 3-0 | -0.8pp |
| 2-1 | **-2.0pp** | | 0-1 | -0.7pp |
| 3-1 | **-1.9pp** | | 2-2 | -0.6pp |
| 0-0 | -1.6pp | | **3-2** | **-0.5pp** |
| 1-0 | -1.6pp | | 0-2 | -1.3pp |

- **해석**: ABS의 고정·표준 존은 사람 심판의 "관대한 모서리/낮은 존" 판정을 제거했다. 피칭 전략상 **공격형/균형 카운트(1-1, 2-0, 2-1, 0-0)에서 모서리를 겨누던 공**이 ABS에선 존 밖(볼) → 제구 실패로 바뀐 것. 반면 **이미 존 한가운데를 강요당하는 3-2·2-2와 웨이스트 목적의 0-1**은 영향이 최소화됐다. 이는 "ABS = 에지 픽처(edge pitcher) 불리"라는 KBO 관측과 일치.
- **부수 효과**: 플래툰 갭이 확대됐다(R: 2023 동손-이손 2.3pp → 2024 2.7pp). 표준 존 아래선 동손 브레이킹볼 유인구의 낙차 판정이 엄격해져 제구 실패가 늘어난 것으로 보인다.
- **모델 함의**: 2024의 카운트×제구 관계는 그 이전 시즌과 계수가 다르므로, 최근년(2023-24) 가중 학습이 필요 (R 3-2 성공률: 2019-22 평균 0.501 → 2023-24 평균 0.462, **-3.9pp** 추가 하락).

### 5-2. 퓨처스(F) vs 정규(R) 제구 수준 — 레이블 레짐 브레이크

- **2019-22**: F 성공률 0.59~0.71 — 정규(R) 0.51~0.55보다 **훨씬 높다**. 야구 상식상 퓨처스 투수의 제구가 더 좋을 수 없으므로, 이 시기 F 데이터는 **더 관대한 운영 존/판정 기준**으로 레이블된 것으로 해석.
- **2023~**: F가 0.473(2023)→0.459(2024)로 급락, **R(0.490)보다 낮아진다**. 즉 F의 제구 판정 기준이 2023년부터 표준으로 통일되어 "실제로는 더 못 하는" 퓨처스 투수들의 진짜 제구 수준이 드러난 것.
- **부수**: post-2023 F는 카운트 구조도 R과 다르다 — 0-0~2-2 구간이 0.46~0.48로 평평(3볼 셀은 표본 부족으로 판정 보류). F 표본의 연도 분포가 R과 달라(이닝×F 교차에서 후반 성공률 상승) 모델이 구식 레짐을 평균으로 섞지 않도록 해야 한다.
- **모델 함의**: `game_type`은 상수 피처로 쓸 수 없다. `F×연도` 상호작용으로 2025 테스트에선 F를 post-2023 레짐(≈0.46)으로 매핑해야 하며, F 카운트 계수는 R과 분리 학습을 권장.
